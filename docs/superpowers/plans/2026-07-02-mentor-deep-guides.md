# Mentor Deep-Guides Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deep, self-contained teaching guide for each of the five mentors (TTrades / Daye / GxT / ICT / Dexter) to the education page, sourced live from NotebookLM, so each mentor's method is fully learnable without watching the videos.

**Architecture:** Five standalone HTML pages under `education/mentors/`, each loading a shared `guide.css` + `guide.js` renderer plus a per-mentor content file `data/<id>.js` (`window.GUIDE`, same embed pattern as the base page's `window.EDU` — works `file://` and served). Content is pre-generated by querying each mentor's NotebookLM notebook and transcribing the cited answers into an 8-section spine. No verdict/backtest layer inside the guides (pure faithful teaching). ICT is bounded to its teaching core.

**Tech Stack:** Vanilla HTML/CSS/JS (zero backend). `notebooklm` CLI v0.3.4 (`~/bin/notebooklm`) for content. `node --check` for JS syntax, the gstack `browse` binary for headless render checks, `python3 -m http.server` to serve.

## The 7 content queries (template; substitute the mentor name)

Ask these against the mentor's notebook, one per section (grounding = section 8, assembled from citations, not a query). Prefix every question with: `You are writing a faithful teaching guide for a student who will not watch the videos. Use only what THIS notebook's sources say. Include exact mechanics and the nuances a student must not miss.`

1. thesis — `In one rich paragraph, what is <NAME>'s core thesis — how does he see and read the market?`
2. model — `Explain <NAME>'s foundational market model in depth, step by step, with its internal logic.`
3. glossary — `Define every key term and piece of vocabulary <NAME> uses. For each: the definition and the nuance a student must not miss.`
4. timing — `When does <NAME> operate — which sessions, times, killzones or calendar windows — and why each one?`
5. setups — `List <NAME>'s signature setups. For EACH, break it down as: market context -> trigger -> entry -> stop placement -> target, plus the must-not-miss nuance.`
6. example — `Walk through one concrete worked example of <NAME>'s highest-conviction setup forming and being managed, as if narrating a live chart.`
7. nuances — `What are the most important nuances, caveats, and common mistakes <NAME> warns about that a student would otherwise miss?`

For ICT, run each query against the 3 bounded notebooks and merge, and keep the concept set to the teaching core (PD arrays, liquidity, killzones, OTE, Power-of-3, MSS, the models the other mentors build on).

**Files:**
- Create: `education/mentors/guide.js`

- [ ] **Step 1: Write the renderer**

```js
/* Mentor deep-guide renderer. Reads window.GUIDE, renders into #guide. Vanilla, no deps. */
(function(){
  var ORDER=[["ttrades","TTrades"],["daye","Daye"],["gxt","GxT"],["ict","ICT"],["dexter","Dexter"]];
  var G=window.GUIDE, host=document.getElementById('guide');
  if(!G||!host){ console.error('GUIDE data or #guide host missing'); return; }
  function esc(s){return String(s).replace(/[&<>]/g,function(c){return{'&':'&amp;','<':'&lt;','>':'&gt;'}[c];});}
  var toc=G.sections.map(function(s){return '<a href="#'+s.id+'">'+esc(s.title)+'</a>';}).join('');
  var secs=G.sections.map(function(s){
    return '<section class="gsec"><h2 id="'+s.id+'">'+esc(s.title)+'</h2>'+(s.html||'<p class="nc">Not covered in this mentor\'s corpus.</p>')+'</section>';
  }).join('');
  var i=ORDER.findIndex(function(m){return m[0]===G.id;});
  var prev=i>0?ORDER[i-1]:null, next=i>=0&&i<ORDER.length-1?ORDER[i+1]:null;
  var nav='<div class="gnav">'+
    (prev?'<a href="'+prev[0]+'.html">← '+esc(prev[1])+'</a>':'<span></span>')+
    (next?'<a href="'+next[0]+'.html">'+esc(next[1])+' →</a>':'<span></span>')+'</div>';
  host.innerHTML=
    '<div class="ghead"><div class="back"><a href="../index.html">← Back to The Framework</a></div>'+
      '<h1>'+esc(G.name)+'</h1><div class="tag">'+esc(G.tagline||'')+'</div></div>'+
    '<nav class="toc">'+toc+'</nav>'+
    '<main class="body">'+secs+'</main>'+nav;
  document.title=G.name+' — Deep Guide';
})();
```
